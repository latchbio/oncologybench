# OncologyBench

**Benchmarking oncology**

OncologyBench tests whether AI agents can analyze and interpret oncology data across core domains of the field, including molecular tumour board decision-making, biomarker-driven treatment selection, pharmacogenomic safety, and translational programme review. This public release contains two evals that are not in the benchmark, but use the same structure and contain the same content as benchmark questions.
